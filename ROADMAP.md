# QMediaCore Roadmap

## Vision

Make QMediaCore the gold standard for cross-runtime media analysis, timeline extraction, and sprite/atlas export, with unmatched reliability, extensibility, and developer experience.

## Near-Term Goals (Q2 2026)

- [ ] Comprehensive unit and integration test coverage for all analyzers, managers, and handlers
- [ ] Per-analyzer and per-manager documentation with usage examples
- [ ] Centralized error handling and logging utilities
- [ ] Initial observability: metrics and tracing for major operations
- [ ] Performance benchmarks for core operations (frame extraction, analysis, export)
- [ ] Security audit: input validation, sandboxing, and safe handling of untrusted media

## Mid-Term Goals (Q3-Q4 2026)

- [ ] Plugin/extension system for custom analyzers, handlers, and pipeline stages
- [ ] API versioning and migration guides
- [ ] Rich developer documentation: architecture diagrams, API docs, usage guides
- [ ] Backward compatibility guarantees for public APIs
- [ ] Fuzz testing and property-based tests for analyzers

## Long-Term Goals (2027+)

- [ ] Built-in observability: advanced metrics, tracing, and error reporting
- [ ] Automated performance regression testing
- [ ] Community-driven plugin registry
- [ ] Support for additional media formats and runtimes
